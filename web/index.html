보기
  • · 카드 클릭 = 씬을 실물 크기로 열기
  • · 탭 = 플로우 전환 (전체 = 모든 플로우 한눈에)
  • · 썸네일 우상단 = 테마 전환(D/L/N) · ＋로 테마 등록
편집
  • · 카드 드래그 = 순서 이동 (다른 분기 라인으로도 가능)
  • · Shift+드래그로 선택 → 우클릭 = 범주로 묶기
  • · 범주 끝 핸들 드래그 = 범위 조절
  • · 라벨·범주 이름 클릭 = 그 자리에서 수정
  • · ＋ = 씬 삽입 (기존 씬 또는 빈 씬)
  • · 카드 호버 ⑂ = 분기 추가 · Add note = 메모
저장
  • · 실행파일(flow-map 바이너리)로 열면 flow.json에 자동 저장
  • · 정적 서버로 열면 localStorage에 우선 저장 —
  •   'flow.json 연결'(실시간 저장) 또는 '내보내기'로 확정
