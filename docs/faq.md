# FAQ · 문제 해결

## 설치 시 경고가 떠요

코드 서명/공증을 하지 않는 구조라 처음 한 번 경고가 나온다.

- **Windows SmartScreen**: 추가 정보 → 실행
- **mac Gatekeeper**: 시스템 설정 → 개인정보 보호 및 보안 → 허용

## 업데이트는 어떻게 하나요

헤더 **⟳ 업데이트 확인** → 새 릴리스가 있으면 설치 파일을 받아 실행하면 끝. private 저장소 릴리스는 `gh` CLI 로그인 또는 ⚙ 설정의 GitHub 토큰이 필요하다.

- 구 `7.x` 설치본에서 `0.7.x`로 넘어올 때는 숫자가 낮아져 자동 확인에 안 잡힌다 — [Releases](https://github.com/youjeonghan/flow-map/releases)에서 한 번 직접 받으면 그다음부터 정상.

## 데이터를 실수로 지웠어요

flow.json이 정본이고 앱은 자동 저장한다. **데이터 폴더를 git으로 관리**하고 있다면 `git log -- flow.json`에서 원하는 시점으로 복구하면 된다. 앱 안에서의 실수는 대부분 Ctrl+Z로 충분.

## 터미널 버튼이 안 보여요

내장 터미널은 pty 모듈이 로드된 경우에만 켜진다(`/api/health`의 `canTerm`). 설치본에는 포함돼 있고, 개발 실행이라면 `npm install`이 정상 완료됐는지 확인.

## Scene 썸네일이 안 나와요

- Scene HTML이 **self-contained**(외부 리소스 최소)일수록 안정적으로 렌더된다.
- 썸네일은 파일 수정 시각 기준으로 캐시된다 — 파일을 저장하면 자동 갱신.
- 일부만 깨진다면 해당 HTML의 스크립트 오류일 가능성이 크다. 카드 클릭(실물 보기)으로 직접 확인.

## 창 제목·작업표시줄 표기

- 프로젝트 열기 전 **길목**, 열면 **길목 — 프로젝트명** (flow.json `service.name`).
- 작업표시줄 아이콘은 길목 로고. 개발 실행(dev)에서는 작업관리자 프로세스명이 Electron으로 보이는 것이 정상(설치본은 길목).
